# 侧边栏重设计

## 目标
重设计 myproxy 主窗口侧边栏，提升导航层次、选中态辨识度和连接状态可见性，同时保持现有页面与导航行为不变。

## 范围
- 修改 `src/ui.rs` 中 `sidebar`、`nav_item` 及其必要的辅助视图。
- 使用现有 GPUI Kit 组件和主题 token，不引入新依赖。
- 保留所有现有导航项、点击行为和节点统计信息。

## 非目标
- 不改动页面内容、路由逻辑、策略数据或 macOS 托管功能。
- 不新增导航页面或持久化字段。

## 验收标准
- 侧边栏有清晰的品牌/上下文头部、分组层次和当前页高亮。
- 连接状态和节点统计在底部以易读方式呈现。
- 现有导航项均可点击且编译通过。

## 验证
- `cargo check`。
- 检查 `git diff`，确认仅涉及侧边栏及 planning 文件。
